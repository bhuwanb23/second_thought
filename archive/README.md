# Archive

This directory contains historical implementation material that is preserved for
reference and provenance. It is not deployed, tested by the canonical workflow,
or the source of truth for the product.

The active application is in [`../product/`](../product/). The archived prototype
was the earlier implementation used to shape the product concept and is retained
under [`prototype/`](prototype/).

The prototype's original Git history is preserved in `prototype-history.bundle`.
